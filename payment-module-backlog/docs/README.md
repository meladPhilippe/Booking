# Document Map

- `README.md` — entry point and navigation.
- `docs/01-epic-and-scope.md` — epic, success criteria, and product boundaries.
- `docs/02-architecture-and-integration.md` — architecture and payment integration concerns.
- `docs/03-discovery-and-readiness.md` — pre-sprint preparation and exit criteria.
- `docs/sprints/` — one Markdown file per sprint, containing that sprint's user stories and acceptance criteria.
- `docs/04-delivery-governance.md` — dependency map, DoR/DoD, risk register, prioritization, team recommendations, and refinement questions.
